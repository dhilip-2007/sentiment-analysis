# Sentiment Analysis App

A simple and beginner-friendly web application that analyzes text and identifies whether the sentiment is **Positive, Negative, or Neutral**.

## 🚀 Features

- 📝 Enter text to analyze its sentiment.
- 😊 Detect positive, negative, and neutral emotions.
- 📊 Display sentiment scores and confidence estimates.
- 🔍 Highlight important words in the text.
- 📜 Store and view previous analysis history.
- 📥 Export analysis history as a CSV file.
- 📱 Responsive design for desktop and mobile devices.
- 💾 Save analysis history using browser local storage.

## 🛠️ Technologies Used

- **HTML5** – Structure of the application.
- **CSS3** – Styling and responsive design.
- **JavaScript** – Sentiment analysis and interactive features.
- **LocalStorage** – Save analysis history in the browser.

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Enter a sentence in the text box.
5. Click the **Analyze** button to see the result.

You can also use the **Live Server** extension in VS Code to run the application.

## 🧪 Example

**Input:**
```text
I love this application. It is amazing and very useful!
```

**Expected result:** Positive 😊

Another example:

**Input:**
```text
This product is terrible and disappointing.
```

**Expected result:** Negative 😞

## ⚙️ How It Works

The application uses a dictionary-based sentiment analysis approach. It checks the text for predefined positive and negative words, calculates a score, and classifies the result as positive, negative, or neutral.

**Note:** This is a beginner-level rule-based project, not a trained machine-learning model. Sarcasm and complex sentence meanings may not be detected accurately.
